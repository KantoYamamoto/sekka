# parser更新と既知入力への到達

2026-09-25、M2 #81。**SwiftSyntax 604.0.0で固定4入力を解析できた。Collectionsの2件は依然0候補で、検索の有用性が改善したとは言わない。**

## 変更と理由

[公式release 604.0.0](https://github.com/swiftlang/swift-syntax/releases/tag/604.0.0)は2026-09-15公開。実験packageの固定依存だけを603.0.1から更新した。検索・表示のSwiftソースと本番packageは変更していない。従来失敗したborrow/mutate構文を読むための更新であり、意味解決や対象toolchainの条件選択は追加しない。判断は[0040](../decisions/0040-reach-before-integration.md)。

隔離scratchでSwift 6.4により46テスト成功。CLIにはget/setとの条件分岐を含むborrow/mutate型宣言を追加し、その未変更宣言へ型注釈から届く位置（1〜12行）と、不正な別ファイルがあれば終了2・部分出力なしになることを確認した。既存9対照を含め計10対照。最初の対照の終端行期待を13と誤記し、実際のソース行数12へ修正した。対象アプリはbuild/実行しない。

## 固定入力の再実行

#77のmanifest、前後commit、3,008ファイルエントリはそのまま。全入力の一覧/ハッシュ照合後、各例2回の終了状態・標準出力・エラー出力の一致を確認した。初回評価器/結果は保存し、今回の結果は別ディレクトリに置く。

これは既知例の回帰であり未見評価ではない。Collectionsの0変更関数はリポジトリの変更関数0という意味ではない。通常diffにはextension内の実装変更やprotocol/associatedtypeの契約変更があり、現索引・検索の入口では拾えない。前回の独立通常レビューが挙げた確認先へは案内できなかった。型注釈から同名宣言へ辿るだけでは、この変更の既存契約や実装との関係を補えない。

## 次の判断

解析失敗を取り除いたので、この標本で到達不足を評価できる状態になった。ここから表示改善や新しい危険ルールへ進まず、変更を入口にする索引と未変更の関係を扱う契約を見直す。extension/準拠/既存利用箇所のどこを根拠として示せば通常diffに情報を足せるか、既知の必要確認先に対して先に条件を定める。今回の入力を再び未見の成功に数えない。M3は保留。
