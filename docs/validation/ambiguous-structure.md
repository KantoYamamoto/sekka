# 同名宣言の構造対応: #41

2026-09-08。保守的な省略で、同名extensionの挿入を既存メンバーの置換に見せる問題を修正する。[判断0024](../decisions/0024-ambiguous-structure.md)。

## 固定入力

Nuke PR #953の[固定SHA](v03-01-results.md)を旧評価器と今回の評価器で比較した。Deprecated.swiftに出ていたtype-references-changed・members-changed・type-addedの3件は、位置のずれによる誤った対応なので出さなくなった。観測は12→9件。他ファイルの観測と本体比較状態は完全一致することをJSONで照合した。

変更ファイルと未比較の本体位置、同名宣言のため構造・本体を対応させないnoticeは残る。新しいtypealiasを個別追加としては示せなくなる。この情報損失を受け入れ、通常diffへの案内を使う。既存宣言との類似度で推測する実装は入れていない。

## 検証

- Swift 55テスト、CLI/Git 27チェック、Python 10テスト、既存15境界probe・設計の問い6ケースが通過。
- 新しい3テストに、前方/中間追加・並べ替え・本当のメンバー変更・削除・条件分岐・一意な別型・完全な片側追加削除を含めた。
- 最初のテスト入力は宣言間の改行不足で構文エラーになった。入力を直して全Swiftテストを再実行した。製品側の解析失敗を成功へ変える修正はしていない。

自己利用の通常diff・新旧出力は、実装コミット後に同じ固定入力で照合して記録する。独立A/Bの実験結果とは別であり、修正後のレビュー利益を測ったものではない。
